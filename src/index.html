                Demo data
                Invented telemetry, for a board with no robot.
              
    
              
              
    
                
              
    
            
    
          
    

          
    
            Demo data is a match on repeat: twenty seconds of auto, then teleop counting down, with a
            drivetrain, a battery under load and a pose driving a circle. It exists for setting a board
            up in the hotel the night before, and for showing someone what a tile does without a robot
            on the cart.
          
    
          
    
            It is off by default and it is never remembered. A dashboard that quietly invents
            telemetry is a hazard, so switching it on is deliberate, the dock button stays lit the whole
            time it runs, and a restart always comes back to real data or to nothing at all. Switching it
            on stands this panel down as well, exactly as a robot enabling does — a live board is what
            matters the moment anything goes live.

    The three rules
    
            
    Everything here answers to these, in order, and they are not negotiable.
    
            
      
              
    1. 
                01
                
      
                  
      It never controls the robot.
      
                  
      FRC requires the official NI Driver Station, and only one driver station may hold the
                     robot connection. There is no code path in this program that opens that socket. It
                     reads NetworkTables and writes only what a dashboard writes — a tunable, an auto
                     chooser selection — and the backend refuses the control namespaces regardless of what
                     the interface asks for.
      
                
      
              
      2. 
              
    2. 
                02
                
      
                  
      Nothing it does may impede driving.
      
                  
      No modal blocks the dashboard. No check gates anything. No update prompt ever lands
                     between a driver and their robot. This panel closes itself the instant the robot is
                     enabled, and every failure degrades to a dimmed number and a quiet chip in a corner,
                     because a console that interrupts is worse than no console.
      
                
      
              
      3. 
              
    3. 
                03
                
      
                  
      It never invents a number.
      
                  
      An unpublished topic shows a dash, never a plausible value. Demo data has to be
                     switched on deliberately and says so on screen while it runs. The .dslog
                     parser refuses versions it does not recognise rather than decoding them into nonsense.
